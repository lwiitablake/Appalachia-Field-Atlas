# Version 3.2

This is a separate release folder. The previous v3.1 folder is unchanged.

- Screenshot-first gallery: arrows, horizontal swipe, keyboard arrows, up to seven position dots, and a current/total count. A failed screenshot is skipped; the overhead crop appears only if no usable screenshots remain.
- Example: search `0073BD97` (High Knob Lookout bobblehead). Two historical game screenshots are bundled locally, so viewing them does not contact an external image server. Each image has its own credit and direct source link. This location also demonstrates the blue/yellow evidence outlines. Screenshot coverage is limited to this example; other locations still need individually reviewed images.
- Swipe down on the blue notes header or press the down-chevron to minimize. Open notes restores the panel. The X closes it. Tapping empty map space minimizes it; tapping outside dialogs and the mobile search drawer dismisses them.
- Removed the doubled mobile sheet rim and the logo's white numeral backing. The A and 76 now have separate spacing.
- Private journal encryption was verified: AES-256-GCM with a passphrase-derived PBKDF2-SHA-256 key (600,000 iterations), random salt and fresh encryption IV. Profile names and encryption parameters remain visible. Public community contributions are public. This is implementation verification, not an independent security audit.

## Installing

Extract `Fallout76-Field-Atlas-v3.2-GitHub.zip` into a separate folder. Copy its contents, including `.github`, `assets`, `data`, `scripts`, and `vendor`, into the existing GitHub repository folder. Preserve the directory structure; do not upload a ZIP as the website. In GitHub Desktop review changes, commit, then Push origin. Wait for the Publish atlas workflow to finish and refresh the website. Existing journal storage remains compatible on the same website origin.
