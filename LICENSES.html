Where the maps come from

AHeroicLlama and Mappalachia contributors prepare the map package and extracted game-record coordinates. Bethesda / ZeniMax created the underlying Fallout 76 game assets. These maps are not independently photographed satellite imagery.

Bundled source release 2.0.5.2 · Rendering methodology · fo76utils rendering tools.

This app converts, resizes and crops those source maps. Regional views use source-cell envelopes with a one-cell margin. The illustrated and military backgrounds are game map artwork supplied through the same release. Screenshot captions identify their individual uploader and file source.
