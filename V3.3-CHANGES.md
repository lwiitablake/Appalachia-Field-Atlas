# v3.3 — separate release

The v3.2 folder and its archive were not modified.

- Footer: CC BY-NC-SA 4.0 for eligible new original editorial content, except where noted. LICENSES.html explains the scope and retained GPL, CC BY-SA and game-imagery rights. This is not a noncommercial license for the whole codebase.
- Downward header swipes now close notes. Native touch handling avoids pointer-cancellation issues; a downward swipe from noninteractive content also closes the sheet when it is already scrolled to the top. Scrolling deeper notes and interacting with images/controls do not dismiss the sheet. The minimize and close buttons remain.
- Nearby discoveries: same coordinate space, within 20,000 game units, up to 12 results; current query/category matches first, then bobbleheads, magazines, caps, armor, cores and other types. Distances are horizontal straight lines, not walkable routes or distances between unrelated interiors. Category filter is independent of main-map layers.
- Zoom image opens a larger in-app viewer with pinch zoom, wheel zoom, +/−, keyboard panning/zoom, drag panning, reset and close. This works for both screenshots and map placeholders. The source resolution is unchanged; magnification cannot add detail.
- World Map selects full Appalachia, eight regional crops, Atlantic City, The Pitt or the full map directory. The second selector lists related interiors/expedition areas. Regional crops use unions of source region/subregion cells, their rectangular envelope and 4096 units of bleed. They are derived views of the existing map, not new maps.
- Regional interior associations are incomplete/inferred from exact outdoor source names and distinctive source editor-ID prefixes. They are labeled as such; the full directory retains all 205 spaces. No exterior doorway coordinates are invented. Expedition districts remain separate source coordinate spaces, not a fabricated stitched panorama.
- The white dashed selection sample has a gray backing in the Map key only. Selected map pins retain their existing style.
- Coordinate help distinguishes internal game-record positions from a player-facing HUD. Bethesda's published settings guidance did not establish a numeric coordinate toggle on PC, Xbox or PlayStation, so no invented activation instructions are provided.
- Persistent map credits identify Bethesda / ZeniMax game assets and link AHeroicLlama's Mappalachia. The licenses page links the pinned release, rendering methodology and fo76utils.

## Validation

34 regression tests passed. Browser checks: Burning Springs filtered to 143 default-layer records and 11 outdoor/interior options; Atlantic City exposed 11 areas. Verified nearby magazine filtering, screenshot loading, viewer zoom doubling rendered width from 707 to 1414 pixels, reset/close controls, header drag dismissal and gray-backed legend. Native two-finger pinch and Safari touch handling still need physical-device validation. The prior focused accessibility review remains included; full WCAG 2.1 AA conformance is not asserted.

## Install

Extract Fallout76-Field-Atlas-v3.3-GitHub.zip. Copy the contents into the repository directory, preserving all folders (including .github). Commit and push using GitHub Desktop, then wait for Publish atlas to finish. Do not upload the ZIP as the website. Keep the v3.2 backup separately. This release adds data/regions.json, navigation.js, photo-viewer.js and LICENSES.html; include them all. Existing local journals remain compatible on the same origin.
