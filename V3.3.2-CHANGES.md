# v3.3.2

- Mobile location notes reach the bottom of the viewport, including safe-area padding.
- Header uses the existing custom geometric SVG favicon. The exact former markup, stylesheet and favicon are preserved in design-backup-v3.3.1, with restoration instructions. This records provenance, not a legal clearance guarantee.
- Inline photographs support pointer dragging, touch panning, wheel zoom, two-pointer pinch, buttons, reset and keyboard alternatives.
- Location photo composer supports up to eight images, ordered overview / approach / detail / extra views, captions and notes. Original attachments must be added in GitHub's issue editor; preparing a draft does not upload them.
- Moderator publication checks both GitHub repository permission and moderators.json (configured for lwiitablake). A preview digest binds publication to the reviewed issue body. Photos are validated and re-encoded before publication. Public submissions remain public while awaiting approval.
- Protected approval runs in GitHub Actions; the static app does not provide a private moderator session or real email authentication. No live account permissions were changed. Follow PHOTO-WORKFLOW.md for the first live workflow run.
- CLOUD-LOGIN.md explains the infrastructure, privacy implications and remaining work for real email accounts and cross-device synchronization.

Upload the CONTENTS of this release folder to the repository root, including .github and .nojekyll. Commit and push. Keep GitHub Pages configured for GitHub Actions. Review PHOTO-WORKFLOW.md before publishing submissions. Older release folders are preserved separately.
