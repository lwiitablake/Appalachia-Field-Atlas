## Install

1. In GitHub Desktop, Fetch origin and Pull origin before copying files, so any newer published photo changes are present.
2. Extract this release into a separate folder. Copy its contents into your repository root, including `.github` and all data/assets folders. Do not upload the ZIP itself.
3. Delete `assets/photos/community/issue-2/1.webp` from your repository if it remains from an earlier release and you want the unwanted map-view image removed as a file. This ZIP omits it; copying files alone cannot remove an old file.
4. Review the changes, commit and Push origin. Keep GitHub Pages set to GitHub Actions. If newer photos were published after the baseline commit, merge their data/details.json and data/community.json records before pushing instead of replacing them with an older snapshot.
5. Reload the site and verify V3.3.9, Resource location filters, Lunch pails and Coolers. Search Monongah with Interiors enabled and click its gray bobblehead icon or the Inside/submap result.
6. To run the new research report, choose Actions → Atlas Source Review → Run workflow. This does not publish data automatically.
