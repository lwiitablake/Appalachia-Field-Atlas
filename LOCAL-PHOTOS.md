# Local photo organizer — v3.3.4

1. Open Local photos in the site header.
2. Choose your Photos_Fallout 76 Appalachia Atlas folder. The browser grants access only after you choose it; the app cannot silently browse your computer. Individual file selection is available where folder selection is unsupported.
3. The default filter is Unassigned. Select one or more thumbnails using their checkboxes.
4. Click Choose location on map. Select a pin or search result; use Show all locations for landmark pins if needed. The organizer reopens with that record's name and ID.
5. Click Assign selected photos here. Assignment is explicit, not triggered merely by clicking the map. The current selected location can also be used directly.
6. Filter Assigned, Assigned to selected location, or All photos to review assignments. Select photos and clear/reassign them when needed. Changing filters or filename search clears the checkbox selection so hidden photos are not accidentally assigned.
7. Export assignments to download a JSON backup. Import merges the backup; matching file assignments are replaced by imported values. Photos are not embedded in that backup.
8. For publication, select at most eight photos assigned to the current location and click Prepare selected photos for publication. Add captions, tags and alt text, then use the existing GitHub attachment/approval workflow.

Original files are never moved, renamed, modified or automatically uploaded. Assignments are unencrypted local browser metadata, independent of encrypted journals and moderator permissions. Clearing browser storage removes them unless exported. The folder is not watched: select it again to refresh its contents or after page reload. Use the same folder root each time; relative path, size and last-modified date identify a photo. Renaming/editing files may require reassignment. Subfolders are included by supported directory pickers. A chosen folder replaces the current preview list but retained assignments are preserved. PNG, JPEG and WebP are supported. Preview selection has no eight-file limit; publication sets retain the eight-photo and eight-MB-per-file limits.
