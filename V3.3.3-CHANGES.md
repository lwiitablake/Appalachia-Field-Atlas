# Version 3.3.3

New independent build containing all changes through the batch-photo update:
- Multi-batch photo selection by drag/drop or Browse files, up to eight photos per location.
- Per-image subject tags, caption, required separate alt text with explanatory placeholder and example, view/distance, reorder and removal.
- Moderator import preserves image metadata and accepts older pending submissions.
- Mobile notes extend to the viewport bottom; image zoom and pan controls are included.
- Git line-ending-tolerant validation and root .gitattributes are included.
- All existing map layers, source credits, local encrypted journals and accessibility improvements are retained.

## Your local photo folder
An empty sibling folder named `Photos_Fallout 76 Appalachia Atlas` was created beside this release folder. It is intentionally outside the website package: originals placed there are not automatically published or uploaded. Nothing watches or imports this folder automatically. Use the photo form to select your files, then attach originals to the original GitHub issue body and follow PHOTO-WORKFLOW.md for review/publication. There is no Supabase service or cloud account synchronization.

## Install
Extract the complete v3.3.3 GitHub ZIP. Copy its contents into the repository root alongside index.html, replacing matching files, including .github and .gitattributes. Remove the misplaced tests/.gitattributes if it remains from an earlier manual copy. Commit and push; use GitHub Actions as the Pages source. The displayed application version will be 3.3.3.
