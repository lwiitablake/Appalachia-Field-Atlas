# V3.1 map clarity update

The illustrated game map is now the initial background. All other backgrounds remain selectable. The Location notes panel has a dark blue header, strong separator and pale body; written directions appear in a rounded yellow **Where to look** card. A new **Map key** button next to Add marker explains all icons, category colors, source rings and journal states. Its screenshot-example button includes a clearly labeled double-outline demonstration; these samples are not fabricated map data.

## Terrain quality

All three Appalachia images in the pinned Mappalachia archive are **4096 × 4096** pixels. The satellite and illustrated maps retain that pixel size in the existing optimized WebP copies, but the conversion uses lossy compression. Most interior renders are reduced to at most 1536 pixels per side. Zooming cannot reveal detail that is absent from these rasters.

The new optional **Terrain / source quality** setting uses four 2048 × 2048 WebP quadrants encoded losslessly from the decoded original `img/wrld/APPALACHIA.jpg`, with no resampling. They cover the same map bounds and total pixel dimensions. This eliminates additional WebP compression loss but does not recover JPEG information already lost upstream, increase resolution, or make the map 3D. It loads approximately 30 MB, and each file is below 8 MB. Existing detail-card overhead crops still use the lightweight terrain copy. No AI upscaling or invented scenery is used.

Map provenance and underlying rights remain as documented in [SOURCES.md](SOURCES.md), including Bethesda's rights and upstream's stated fair-use basis. Preserving the original raster quality does not imply a new license or express permission. All renders are still used as annotated location-reference surfaces, not standalone artwork. Run `python scripts/build_native.py /path/to/Mappalachia.zip` after a base import to regenerate the native terrain layer.

## Names and acronyms

**NAR = New Appalachian Railroad.** [98 NAR Regional](https://fallout.fandom.com/wiki/98_NAR_Regional) is a derailed-train location; 98 is part of the location/train name, not a player level or coordinate. See also the [railroad article](https://fallout.fandom.com/wiki/New_Appalachian_Railroad). This short factual explanation is written for the atlas and links its source. Cards whose names contain NAR have a keyboard/tap-expandable **What does this name mean?** explanation. PA markers are defined as Power armor in the key and matching cards. C.A.M.P. is described as the player-built camp system. Unverified letter/number codes are not given invented expansions; this is an extensible glossary, not a claim to explain every source editor ID.
