# v3.3.1 corrective release

The supplied screenshots showed v3.3 HTML with a v3.2 runtime and older styles. Browser caching or an incomplete file replacement can cause this combination; the remote deployment cause was not independently established. This release loads its complete JavaScript module set and stylesheet from a new version-specific runtime directory, and requests fresh data. Version consistency and bundled-source consistency are tested automatically.

World Map now lists Appalachia, Atlantic City, The Pitt and the complete directory. Under Appalachia, a single-select region menu offers all regions or one regional crop; the interior selector uses Outdoors instead of Appalachia and lists the related interiors. Prior limitations on inferred regional interior associations remain documented.

Photo-only filtering was browser-verified to show one result (High Knob Lookout) and one blue/yellow pin in the bundled dataset. Both checkboxes still mean either source type, as the label explains. Cyan-blue rings are thicker and bordered in dark ink. Clusters now preserve evidence outlines when any member has the corresponding evidence; a cluster ring does not mean every member has it.

Detail images now have visible minus, plus, percentage, Reset and Expand image controls. Inline zoom was verified from 100% to 150% and back, with the rendered transform checked. Expand image retains the larger pinch/wheel/pan viewer. Source images and their limits are unchanged.

The license footer remains inside the viewport, the navigation has a Map credits & licenses link, and map-source attribution is larger. Credits retain the individual game-asset, map-preparation, screenshot-uploader, software and prose distinctions and original-source links.

## Updating your GitHub copy

1. Extract the entire v3.3.1 ZIP into a new folder.
2. Copy all extracted contents into your repository, replacing matching files and preserving subfolders. Include assets/runtime-3.3.1 in full; do not copy index.html alone.
3. Commit and push in GitHub Desktop. Wait for Publish atlas to succeed.
4. Reload the website. Both the tab title and the page edition must say v3.3.1. If the old HTML persists, use Ctrl+Shift+R once (or close and reopen the mobile tab).

Previous local release folders are unchanged. The automated release builder and RELEASE-CHECKLIST.md make version and accessibility validation repeatable for future releases.
