# v3.3.11 — individual pickup checklist

Built October 9, 2026 as a separate copy of v3.3.10. No previous development folders were changed. This build does not fetch or overwrite any newer GitHub contributions.

Open **Individual pickup items · checklist** in the sidebar. All individual choices are OFF on each new page load. Search a name, optionally choose a category, and check the items you want on the map. Use **Show selected items only** or **Clear this checklist** to manage your choices. **Show 50 more items** makes the full alphabetical list accessible without a search. Selecting an item retains other selected items.

The checklist contains 2,630 named item types with 131,248 source placements, including seven InstaMash and seven Dandy Boy Apples placements across all maps. Some placements are interior-only; enable interior resources to see gray entrance markers where an entrance is mapped. Existing dedicated collectible layers retain their controls.

These are the known named placements in the bundled Mappalachia 2.0.5.2 data, not an exhaustive list of all possible inventory items or randomly generated loot. The source edition has not been refreshed in this UI update. Quest conditions, locks, ownership and player collection can affect availability. Original source: https://github.com/AHeroicLlama/Mappalachia/releases/tag/2.0.5.2 . No new images or copied guide text were added; existing credits and rights remain unchanged.

## Install
Fetch and pull your repository first. Preserve any newer photo contributions made since your v3.3.10 copy before replacing data files. Extract the new ZIP and copy its contents into the repository root, including .github; keep .git untouched. Commit, push and wait for Pages deployment. The header should say v3.3.11. Do not upload the ZIP itself.
